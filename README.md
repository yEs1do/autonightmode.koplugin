# KOReader 自动显示调节

**自动显示调节**（`scheduleddisplay.koplugin`）是一个 KOReader 插件，用时间表统一管理电子墨水阅读器的**前光亮度、色温和夜间模式（反色）**。

> 当前正式版本：0.1.1

## 语言支持

从 **0.1.1** 开始，插件界面会自动跟随 KOReader 当前语言设置。

- **简体中文**：保持中文界面。
- **English**：自动显示英文界面。
- 其他语言目前回退到插件默认的中文文本，不影响功能使用。

插件自带英文翻译模块和翻译表，无需修改 KOReader 本体。

## KOReader 菜单结构

安装并启用插件后，在 KOReader 中的入口及菜单层级如下：

```text
设置
└── 屏幕
    └── 自动显示调节
        ├── 自动调节：已启用 / 已停用
        ├── 时间表
        │   ├── 添加时间点
        │   ├── 07:00  亮度18·色温6·反色关
        │   ├── 18:00  亮度12·色温18·反色不调整
        │   └── 23:00  亮度6·色温不调整·反色开
        │       └── 点击后进入编辑
        │           ├── 时间
        │           ├── 前光亮度
        │           ├── 色温
        │           └── 夜间模式（反色）
        ├── 立即切换
        ├── 亮度与色温变化：平滑 / 立即
        ├── 变化时间：5–60 秒
        └── 自动切换提示：开启 / 关闭
```

实际显示的菜单项目会根据设备能力变化：没有前光时隐藏亮度选项，没有自然光/暖光时隐藏色温选项，不支持夜间模式时隐藏反色选项；检测到 AutoWarmth 冲突时，菜单顶部还会显示提示。

## 主要功能

- 最多 **24 个时间点**
- 时间精度 **5 分钟**
- 时间点自动按时间排序
- 打开“时间表”后，单击时间点：编辑
- 长按时间点：确认后删除
- 新增或修改时间点后只保存设置，不立即改变当前显示；新增时间点会提示三个参数均为“不调整”，可返回时间表点击该时间点继续编辑；使用“立即切换”手动执行当前有效状态
- 删除最后一个时间点：自动停用
- 每个参数都可以设置为 **不调整**
- 前光使用设备原生档位；PW5 为 **0–24**
- 色温使用设备原生档位；PW5 为 **0–24**
- 无对应硬件/能力时自动隐藏该选项
- 提供“立即切换”按钮，可手动执行当前有效时间点
- 支持立即变化
- 支持 5–60 秒、5 秒步进的平滑变化，默认 5 秒；亮度与色温按同一时间轴连续推进
- 平滑变化时亮度与色温同步，使用高精度单调时间计算进度，并采用缓出/缓入曲线
- 启用后立即应用当前时间表
- 唤醒后重新计算当前状态并立即校正
- 手动调整覆盖当前状态，直到下一次计划时间点
- 不关闭其他插件；检测到 AutoWarmth 冲突时仅提示
- 默认不弹切换通知，但可以手动开启

## 默认时间表

首次使用默认：

| 时间 | 前光 | 色温 | 夜间模式 |
|---|---:|---:|---|
| 07:00 | 18 | 6 | 关闭 |
| 18:00 | 12 | 18 | 不调整 |
| 23:00 | 6 | 不调整 | 开启 |

因此每天形成：

`07:00 白天 → 18:00 傍晚 → 23:00 夜间反色 → 次日 07:00 恢复白天`

## “不调整”和 0 的区别

`亮度 0` 是真实设置：**关闭前光**。

`不调整` 是控制语义：**不要修改当前值，继续继承最近一次有效状态**。

例如：

```
18:00  亮度 12 · 色温 18
23:00  亮度 6  · 色温 不调整 · 反色开
```

23:00 后色温仍保持 18，只降低前光并开启反色。

三个参数均可在编辑界面恢复为“不调整”。

## 编辑时间点

点击时间点后：

- 时间
- 前光亮度
- 色温（设备支持时）
- 夜间模式（设备支持时）

均可单独编辑。

新增时间点时三个参数默认全部“不调整”，避免只想修改一个参数时意外改变其他参数。

同一时间不能存在两个节点；添加已存在时间会直接进入已有节点编辑。

## 平滑变化

选择“平滑”后可以设置：

`5 / 10 / 15 / … / 60 秒`

默认 5 秒。

亮度和色温使用同一时间轴同步变化，并采用类似 KOReader 调暗器的缓出/缓入非线性曲线。夜间模式不渐变，到节点时直接切换。

如果平滑过程中用户真正手动改变亮度或色温，当前渐变会立即停止；普通翻页或普通界面操作不会无故中断。

## 设备兼容

插件不会把 Kindle Paperwhite 5 的 24 档写死。

界面使用当前设备的原生档位；内部保存为设备无关的归一化数值。因此：

- PW5 可以直接显示亮度/色温 0–24。
- 其他设备使用自己的原生最大值。
- 没有前光：隐藏亮度。
- 没有自然光/暖光：隐藏色温。
- 不提供夜间模式接口：隐藏反色。

## AutoWarmth

自动显示调节不会关闭、修改或接管 AutoWarmth。

如果检测到 AutoWarmth 可能同时控制色温、夜间模式或前光，插件只显示提示。建议不要让两个自动时间表同时控制同一个参数。

## 安装

把：

```
scheduleddisplay.koplugin/
```

复制到 KOReader：

```
koreader/plugins/
```

重启 KOReader 后，在：

```
设置 → 屏幕 → 自动显示调节
```

中使用。

设置保存在 KOReader 设置目录的：

```
scheduleddisplay.lua
```

## 注意

本项目需要在实际设备上验证前光、色温、反色以及休眠/唤醒行为。不同 KOReader 版本或不同设备后端可能存在接口差异。
